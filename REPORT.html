4. Key Architectural Decisions

  1. PostgreSQL Advisory Transaction Locks: Eliminated Redis complexity; pg_advisory_xact_lock automatically releases on transaction commit/abort.
  2. Transactional Outbox: Notifications are stored atomically with booking updates, preventing phantom emails if a transaction rolls back.
  3. Eager Hold Expiration: Stale holds are purged inline on slot queries and hold mutations, freeing spots the instant 5 minutes lapse.
  4. Materialized Buffer Boundaries: Storing buffered_start and buffered_end enables ultra-fast GiST range queries.
